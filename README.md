## 📁 File Naming Convention

Each folder follows a uniform file naming scheme:

| File Type           | Format                           | Example                |
| ------------------- | -------------------------------- | ---------------------- |
| Module PPTs / Notes | `<sub>-mod-<num>-part-<num>.pdf` | `bda-mod-2-part-1.pdf` |
| Question Bank       | `<sub>-<exam>-qns.pdf`           | `ml-ise-1-qns.pdf`     |
| QB Solutions        | `<sub>-<exam>-sol.pdf`           | `devops-ise-1-sol.pdf` |
| FA Resources        | `<sub>-fa-<num>.pdf`             | `ctd-fa-1.pdf`         |
| Updated Syllabus    | `<sub>-syllabus.pdf`             | `wair-syllabus.pdf`    |

## 🧠 Usage Instructions

- Click on a subject folder to explore resources.
- Download PDFs for offline use.
- Use QB + Solutions for exam practice.
- Refer updated syllabus for recent changes in modules.
